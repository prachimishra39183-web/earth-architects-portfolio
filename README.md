# Earth Architects Showcase

Create a premium, high-end, modern architecture and interior design portfolio website for a company called "Earth Architects".

The website should feel like a real professional architecture studio website that can be presented to a paying client. Do NOT make it look like a generic template, student project, SaaS website, or ordinary business website.

The overall visual direction should be:
- Luxury
- Minimal
- Editorial
- Sophisticated
- Architectural
- Premium
- Image/video focused
- Strong use of whitespace
- Elegant typography
- Smooth cinematic animations
- High-end architecture magazine aesthetic

BRAND:
Company: Earth Architects

Use the provided Earth Architects logo.

The website should showcase their architectural work and convert visitors into potential clients.
